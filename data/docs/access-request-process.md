# Data Access Request Process

## Requesting access
Employees request access to a governed table through the access portal. Each request names the table, the business purpose and the expected duration.

## Approvals
Requests for tables tagged confidential need approval from both the data owner and the information security team. Requests for internal tables need only the data owner's approval. Approvals are expected within two business days.

## Access reviews
Access to confidential tables expires after 180 days and must be renewed. Data owners review all active grants every quarter and revoke access that is no longer needed.
